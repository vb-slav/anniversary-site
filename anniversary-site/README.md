# Наша годовщина — небольшой сайт-поздравление

Статический сайт на HTML, CSS и JavaScript. Не требует сервера, сборки или API. Адаптирован под мобильные экраны, в том числе размер iPhone 14 (390 × 844 CSS px).

## Как заменить фотографию и музыку

Создай папку `assets` (она уже есть) и положи в неё:

- `our-photo.jpg` — фотографию для страницы после нажатия «Да».
  - Если хочешь GIF, положи `our-photo.gif` и в `index.html` замени `assets/our-photo.jpg` на `assets/our-photo.gif`.
- `our-song.mp3` — нужный музыкальный трек. После нажатия «Да» сайт попробует запустить его автоматически.

На iPhone Safari звук разрешается запускать после действия пользователя. Поэтому старт музыки привязан непосредственно к нажатию кнопки «Да». Если файл не добавлен или браузер не смог его запустить, на странице появится подсказка.

## Локальный просмотр

Открой `index.html` в браузере. Для проверки через локальный сервер можно выполнить в этой папке:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Публикация через GitHub Pages

1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория все файлы и папку `assets`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. После публикации GitHub покажет адрес сайта в разделе Pages. Его можно открыть с iPhone и любого другого устройства.

> Если репозиторий публичный, добавленные фотография и MP3-файл тоже будут доступны посетителям сайта по прямым ссылкам. Не загружай туда материалы, которые не хочешь делать публичными.
